# Version 1.1 browser and print checks

All checks used existing local software, a temporary browser profile and loopback servers. No packages were installed. External page requests were blocked; the retained run observed none. Previous evidence is unchanged.

- 42 layout states passed: seven routes at 320, 768 and 1280 px in light and dark schemes. No document overflow, duplicate IDs or visible controls below 24 by 24 CSS pixels were found.
- The 320 px action log stayed inside the page in both schemes. Its named region is keyboard-focusable and arrow keys scroll it. Maximum-length unbroken titles and reasons also produced no page overflow.
- Accessibility-tree checks covered every visible input, select and button in 43 states, with 733 named control observations. There were 45 local WCAG 2.1 A/AA scans and zero violations. Some colour-contrast nodes still require manual review. Separately, 24 stylesheet text-colour pairs passed 4.5:1, minimum 6.108:1. These are bounded checks, not conformance certification.
- The board's visible banner, heading, status ordering, paired symbols and words, local dates and time-zone setting were checked. The repeated 1:30 a.m. hour on 1 November 2026 exported as two distinct instants with -07:00 and -08:00 offsets. The synthetic Vancouver calendar is pinned to the requested seasonal-clock rules because the browser and server databases differ.
- Keyboard-only workflows passed on all seven routes, including check-in and shift saves, board creation, zone and print-size selection, log scrolling, rider-card print activation, JSON export and confirmed clearing.
- Real device-storage operations checked demo duplicates, both forms, required Not done reasons and retained status history. Downloaded action-log CSV and complete JSON are retained.
- The sample board fits on one Letter portrait page and one 17 by 11 inch Tabloid landscape page. The rider card remains one Letter page. Twelve maximum-length synthetic actions produce six pages per board layout. PDF inspection verified all 14 board pages contain exactly one demonstration banner, a station heading and both required footer lines. Text is at least 13 pt on Letter and 18 pt on Tabloid after PDF transformation.
- With the local server stopped, all seven routes were fully reloaded, showed Offline ready and preserved the synthetic records. A separate repository-subpath fixture upgraded the old cache to version 1.1.0, preserved a check-in and shift, removed the old application cache and reloaded every route offline.
- The final browser run recorded zero page or console errors and zero external page requests. Local servers and temporary browser profiles were closed.

## Corrections during checks

The initial browser date check exposed the database disagreement, so the explicitly requested synthetic calendar was pinned and documented. Native select key sequences were adjusted to use readable city labels. Print settings are selected in screen mode before print emulation. An early print check found that an oversized table header prevented repetition; the compact two-column print header now repeats on every page. The final retained runs are complete and passing.
